# Founder portraits

Drop the photographs here, then swap the stand-in initials for an image in
`founders.html`:

```html
<div class="founder__portrait">
  <img src="assets/img/founders/bruce.jpg" alt="Dr. Bruce Lautenschlager">
</div>
```

| File | Founder |
| --- | --- |
| `bruce.jpg` | Dr. Bruce Lautenschlager |
| `allen.jpg` | Allen Hayne |

The frame is a circle and the image is fitted with `object-fit: cover`, so the
photograph crops to the circle rather than squashing into it. Any shape works;
roughly square crops centred on the face look best. No resizing needed.
